# 飞书多维表导出边界

`scripts/export_feishu_csv.py` 生成的是本地 UTF-8 BOM CSV 预览，不是飞书 API 写入器。这样可以先在本地查看字段、过滤结果和敏感信息，再由用户选择导入或授权连接器。

## 默认列

```text
笔记标题,来源链接,来源ID,搜索关键词,内容分类,素材类型,发布时间,点赞,评论,收藏,指标门禁,门禁理由,证据状态,核心矛盾,评论区主要观点,高赞评论原文,二创价值,本地图片,同步状态
```

## 写入前检查

1. `source_url` 和 `source_id` 能回到原始记录；
2. `gate_status` 是 `eligible`，`local_review` 不得默认导入；
3. 评论原文、图片和正文的使用权已确认；
4. 字段类型与目标表一致，数值字段不带中文单位；
5. CSV 打开预览无公式注入、乱码、列错位或绝对路径；
6. 真实写入目标、账号权限和回滚方式已确认。

不保存飞书 App Secret、用户 Cookie 或个人 Token。没有连接器时，只交付 CSV 并写 `feishu_sync: missing_evidence`。
